# Lorensic Natural Disasters

Lorensic Natural Disasters is a Minecraft plugin that adds realistic natural disasters to your server. It features tornados, hurricanes, lakebursts, tsunamis, and flashfloods, with varying intensities and locations. The plugin includes realistic effects such as rain puddles, rain particles, water vapor particles, and a realistic water gravity system. It also supports whirlpools and can carry or push blocks with the wind.

## Install

1. Download the plugin JAR file from the [releases page](https://github.com/EnderDevelopment/LorensicNaturalDisasters/releases).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your server or use the command `/reload` to load the plugin.

## Use

1. Use the command `/disaster <type> <intensity> <location>` to spawn a natural disaster.
   - `<type>` can be `tornado`, `hurricane`, `lakeburst`, `tsunami`, or `flashflood`.
   - `<intensity>` can be `1` to `5` for tornados and hurricanes, or `small`, `medium`, or `large` for lakebursts, tsunamis, and flashfloods.
   - `<location>` can be `here` to spawn the disaster at your current location, or a specific coordinate in the format `x,y,z`.
